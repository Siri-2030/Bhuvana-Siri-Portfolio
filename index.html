       4. answer in the user's language

MLOps: CI/CD pipeline for machine learning
GitHub Actions | 2026 | Course project, MLOps (24SDAD03)
      
    
        
  • Every push lints, validates data, trains, tests, gates, containerises, deploys and monitors a wine-quality Random Forest.
    • 
        
  • A model below 0.70 accuracy or 0.65 macro-F1 exits with code 1, so Docker build and deployment never run. I proved it by setting the threshold to 0.99.
    • 
        
  • Data versioned with DVC, runs tracked in MLflow, served by FastAPI in Docker, monitored with Prometheus and Grafana.
    • 
      

      
0.7469 accuracy0.7096 macro-F144 of 44 tests passCI ~2 min

      
scikit-learnDVCMLflowGitHub ActionsDockerFastAPIPrometheusGrafana

      
Pipeline
push -> CI: ruff lint -> dvc pull -> data checks
            -> train + log to MLflow -> 44 pytest tests
            -> validation gate (acc >= 0.70, F1 >= 0.65)
            -> docker build
CI success -> CD (workflow_run): push to GHCR (latest + SHA)
            -> deploy -> health check -> /metrics -> Grafana
